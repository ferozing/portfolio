# PM Feroz — concept v2

This is a separate portfolio direction. The original site in the parent directory is unchanged.

## Run this concept

```sh
npm install
npm run dev
```

The concept runs at `http://127.0.0.1:4322` so it can sit beside the original preview on port 4321.

For a production check:

```sh
npm run build
npm run preview
```
